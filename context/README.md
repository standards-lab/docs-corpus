# docs-corpus context

The corpus the workspace's real workloads run over: docproc's and docinfer's acceptance, and
capstone.data-intelligence's. It starts from the local pool at `~/docs` (592 files, 1.7 GB,
`MANIFEST.json` dated 2026-11-06), which docproc's acceptance ran over, and becomes a curated,
versioned corpus in this repository, public from v1 ([README.md](../README.md)).

## Capability map

- **Inventory** (built): every adopted sample's and its truth and doc files' source, license,
  truth, and redistribution flag in `MANIFEST.json`, with `version` naming the schema version,
  and the layout by format directory, generated by `mise run manifest`
  ([README.md](../README.md#the-manifest)). The candidates are planned.
- **Scenario index** (built): each sample's `covers` in the coverage vocabulary, equal to its
  covers in `docs/coverage.json`, with no sample's covers inside another's
  ([docs/coverage.md](../docs/coverage.md#the-manifest)).
- **Coverage page** (built): the scenario vocabulary, each `~/docs` sample's disposition, and
  each gap's candidate ([docs/coverage.md](../docs/coverage.md)).
- **Distribution** (built): `mise run pack` writes one uncompressed tar per format area of the
  sample files, and `mise run fetch` reads them from a release URL or a directory and places each
  file once it matches the manifest's size and sha256 ([README.md](../README.md#distribution)).
  Publishing them on each version tag is planned, in snapshot.
- **Baseline** (planned): docproc's and docinfer's run over each version, the reference timings
  capstone.data-intelligence measures against.
- **Check** (built): the Go gates for [tools/coverage](../tools/coverage), from build to
  golangci-lint, the [manifest checks](../docs/coverage.md#the-manifest), the
  [coverage checks](../docs/coverage.md#the-check), and `lint-context` and `lint-references`
  ([scripts/check.sh](../scripts/check.sh)), with the tools pinned in [mise.toml](../mise.toml). No
  CI runs it.
